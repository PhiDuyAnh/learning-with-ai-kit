# Session notes

Load **notes-format** first.

1. **List what was covered.** Go back through the session: the ideas that were taught or clarified, what the user got right, what is still unclear.
2. **Propose before writing.** Show the list in a few lines: the session log, plus which concept notes you'd create or update. Let the user drop or add items.
3. **Write concept notes** for each idea, using **link-notes** to update existing ones instead of duplicating.
4. **Write the session log** in `sessions/`, linking every concept note.
5. **Update** the topic index (add the session and any new concepts), the glossary, and `_learner.md` ("Where we stopped").
6. **Confirm** with a short list of the notes written or updated.
