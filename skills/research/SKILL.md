# Research

**Never trust your own memory for facts you are about to teach.** One confident mistake makes the user doubt everything else.

## When to research

- Before planning a lesson or roadmap: map the topic (core concepts, standard explanations, common misconceptions, best sources).
- Mid-conversation: the moment you are unsure of a fact, name, date, number, formula, or definition, check it before saying it.
- When the user asks for references.

Skip it for things you are certain of and that don't change (basic arithmetic, well-settled definitions). Pausing to verify is always acceptable. Accuracy beats flow.

## How

For anything more than a single lookup, delegate to the **researcher** agent so the search results stay out of the main conversation. Give it a self-contained question, the learner's level, and what the answer is for. For a single fact, search directly.

## Source quality

Prefer, in order:

1. Primary and official sources: specs, official docs, the original paper, textbooks, standards bodies.
2. Respected teaching sources: university course pages, well-known educators, established references.
3. Practitioner writing with clear expertise.

Drop SEO filler, content farms, and unsourced listicles. Prefer recent sources for fast-moving topics.

## Output

- Cite inline as markdown links, right next to the claim they support.
- If sources disagree, say so in one sentence and say which you trust and why.
- If a check corrects something you said earlier, say so plainly.
- When a topic folder exists, add useful sources to `RESOURCES.md` there: one line each with title, link, type (doc, video, book, course), level (intro, intermediate, advanced), and why it is good.

Write the answer through **plain-explain**.
