# Notes check

Load **notes-format** first to find the notes.

1. **Gather.** Read the topic index, then the concept, source, and session notes in scope. Scope can be a topic, a date range ("this week"), or one note.
2. **Choose the mode** if it isn't clear:
   - **Recap:** a short plain summary of what the notes cover, plus anything marked "Still unclear".
   - **Check:** questions drawn from the notes, run the way **check-me** does (feedback, adapt difficulty, summary at the end).
3. **Stay inside the notes** for the questions. If a note looks wrong or outdated, say so, check with **research**, and offer to fix the note.
4. **End** with what's solid and what's shaky. Offer to update `_learner.md` and to add a "Still unclear" callout to notes where they struggled.

This is on demand only. Never suggest a review schedule.
