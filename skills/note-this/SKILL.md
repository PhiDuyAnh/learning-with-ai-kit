# Note this

Turn what was just explained into a distilled note. Load **notes-format** first.

1. **Pick the idea.** What exactly should be saved? If the last few turns covered more than one idea, ask which, or write one note per idea.
2. **Find the home.** Run **link-notes** to check for an existing note on this idea. If one exists, update it instead of creating a new one.
3. **Write it** with the concept-note template. Rewrite in plain, standalone words. Don't paste the chat. Keep the example that made it click.
4. **Connect it.** Add links to the ideas it builds on, add it to the topic index, and add any new terms to the glossary.
5. **Confirm** in one line: the note's name and path, and whether it was new or updated.
